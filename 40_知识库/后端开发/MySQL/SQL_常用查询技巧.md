# SQL_常用查询技巧

SQL 常用查询技巧包括 JOIN、聚合、窗口函数、CTE、子查询、分页和执行计划分析。

## 查询设计流程

```mermaid
flowchart LR
  A[明确问题] --> B[确定表和关联]
  B --> C[写过滤和聚合]
  C --> D[查看执行计划]
  D --> E[补索引和改写 SQL]
```

## 实践检查清单

- JOIN 条件是否明确，避免笛卡尔积。
- WHERE 条件是否能利用索引。
- 分页是否避免深 offset 带来的扫描成本。
- 聚合和窗口函数是否先缩小数据范围。
- 上线前是否用真实数据量查看执行计划。

## 案例

查询每个用户最近一笔订单，可以用窗口函数按用户分组排序取第一条；旧版本 MySQL 可用子查询或 JOIN 最大时间，但要注意同一时间多条记录的处理。

## 常见误区

- 只在少量测试数据上验证 SQL。
- SELECT 取出所有列，增加网络和回表成本。
- 复杂查询不看执行计划，慢了才临时加索引。
