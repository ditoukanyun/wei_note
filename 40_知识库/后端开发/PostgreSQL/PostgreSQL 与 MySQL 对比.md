# PostgreSQL 与 MySQL 对比

## 定义

PostgreSQL 与 MySQL 都是主流关系数据库。PostgreSQL 更强调标准 SQL、复杂查询和扩展能力；MySQL 生态广泛，Web 应用使用非常普遍。

## 对比要点

- PostgreSQL 在复杂查询、JSONB、扩展和全文检索方面能力强。
- MySQL 运维经验和业务生态更普及。
- 选型应结合团队经验、数据模型、查询复杂度和运维能力。
