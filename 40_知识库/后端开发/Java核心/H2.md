# H2

H2 是 Java 生态常用的轻量级内存数据库，适合本地演示、测试和简单原型，不适合作为复杂生产数据库替代。

## 相关概念

- [[SpringBoot]]
- [[PostgreSQL 核心能力总览]]
- [[MySQL/MySQL_高级操作总览]]

## 使用流程

```mermaid
flowchart LR
  A[引入 H2 依赖] --> B[配置内存或文件模式]
  B --> C[执行 schema 和测试数据]
  C --> D[运行测试]
  D --> E[清理或重建数据库]
```

## 实践检查清单

- 是否只把 H2 用于本地演示、单元测试或轻量集成测试。
- SQL 方言是否和生产数据库存在差异。
- 测试是否覆盖迁移脚本，而不是只依赖自动建表。
- 内存模式和文件模式是否按测试隔离需求选择。
- 关键查询是否仍在真实数据库上验证执行计划。

## 案例

Spring Boot 教学项目可以用 H2 快速演示 CRUD，但涉及 JSONB、窗口函数、锁行为或复杂索引时，应切换到 PostgreSQL 或 MySQL 容器测试。

## 常见误区

- H2 测试通过就认为生产数据库一定通过。
- 使用 H2 特有语法，迁移到生产库失败。
- 测试之间共享同一个内存库，造成数据污染。
