# 倒排索引与分词器

## 定义

倒排索引是从词项到文档的映射结构，能快速找到包含某个词的文档。分词器决定文本如何切分、归一化和写入倒排索引，是全文检索质量的基础。

## 要点

- 正排索引从文档找字段，倒排索引从词项找文档。
- 分词器通常包含字符过滤、Tokenizer 和 Token Filter。
- 中文搜索需要特别关注中文分词、同义词、停用词和大小写归一化。
- `text` 字段用于全文搜索，`keyword` 字段用于精确过滤、排序和聚合。

## 建索引流程

```mermaid
flowchart LR
    A["原始文档"] --> B["字符过滤"]
    B --> C["Tokenizer 分词"]
    C --> D["Token Filter 归一化"]
    D --> E["倒排索引"]
    E --> F["词项 -> 文档列表"]
```

分词器决定“什么词会被搜索到”。同一段文本使用不同分词器，写入倒排索引的词项可能完全不同。

## 示例

文本：“苹果手机保护壳”

- 粗粒度分词可能得到：`苹果手机`、`保护壳`。
- 细粒度分词可能得到：`苹果`、`手机`、`保护`、`壳`。
- 同义词扩展可能加入：`iPhone`、`手机壳`。

如果用户搜索“iPhone 手机壳”却搜不到这条商品，问题可能不是查询 DSL，而是分词和同义词没有覆盖。

## 检查清单

- 字段是全文搜索还是精确过滤，是否正确选择 `text` 或 `keyword`。
- 中文分词是否适配业务词库、品牌词和专业词。
- 搜索词和索引文本是否使用兼容的 analyzer。
- 同义词和停用词是否有版本管理和灰度验证。
- 分词变更是否需要重建索引。
