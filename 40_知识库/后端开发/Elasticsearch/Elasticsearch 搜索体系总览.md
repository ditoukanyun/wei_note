# Elasticsearch 搜索体系总览

## 学习目标

- 理解 Elasticsearch 适合解决什么搜索问题，不适合替代什么数据库能力。
- 掌握索引、文档、分片、副本、倒排索引、分词器和查询 DSL 的基本概念。
- 能设计数据库到 Elasticsearch 的同步方案和基础搜索接口。

## 核心概念

- **索引**：一组结构相似文档的集合。
- **文档**：可被搜索和聚合的 JSON 数据。
- **倒排索引**：从词项映射到文档，是全文检索的核心结构。
- **分词器**：决定文本如何切分、归一化和建立索引。
- **查询 DSL**：用 JSON 描述过滤、匹配、排序和聚合。
- **相关性**：通过评分模型决定搜索结果排序。

## 工程实践清单

- Elasticsearch 适合作为搜索和分析引擎，不适合作为强一致主数据库。
- 搜索索引字段需要围绕查询场景设计，而不是机械复制数据库表结构。
- 字段类型要先区分全文搜索、精确过滤、排序和聚合，尤其注意 `text` 与 `keyword`。
- 数据同步需要考虑全量构建、增量更新、失败重试和一致性延迟。
- 中文搜索重点关注分词器、同义词、停用词和相关性调优。
