# OpenFeign

## 定义

OpenFeign 是声明式 HTTP 客户端，允许开发者用接口和注解描述远程调用，由框架生成请求实现。它常用于 Spring Cloud 服务间调用。

## 要点

- 接口方法映射远程 HTTP API。
- 需要配置超时、日志、错误解码和重试策略。
- 与 [[Resilience4j]] 配合可实现熔断、限流和降级。
- 远程调用边界必须关注 [[超时控制]] 和 [[幂等性]]。

## 调用流程

```mermaid
flowchart LR
  A[业务服务] --> B[Feign 接口代理]
  B --> C[编码请求参数]
  C --> D[远程 HTTP API]
  D --> E[解码响应或错误]
  E --> F[返回业务结果]
```

## 实践检查清单

- 是否为连接超时和读取超时设置明确数值。
- 是否区分 4xx 业务错误、5xx 系统错误和网络错误。
- 重试是否只用于幂等请求，避免重复创建订单或扣款。
- 是否接入熔断、限流、隔离和降级，防止远程服务拖垮调用方。
- 日志是否能记录目标服务、接口、耗时、状态码和 TraceId。

## 案例

订单服务调用库存服务扣减库存时，不应无脑重试所有失败。库存扣减如果不是天然幂等，应先设计请求唯一号和幂等表，再允许有限重试；否则网络抖动可能造成重复扣减。

## 常见误区

- 把 Feign 接口当本地方法使用，忽略网络失败和延迟。
- 默认超时过长，线程被远程服务占满。
- 在 Feign 层吞掉异常，导致上层无法做正确补偿或降级。
