# Node.js 后端开发总览

## 定义

Node.js 后端开发是使用 JavaScript 或 TypeScript 在服务端构建 API、BFF、实时通信、任务处理和工具链服务的实践。它的优势在于前后端语言统一、I/O 密集型场景效率高、生态丰富，限制在于 CPU 密集任务和运行时治理需要额外设计。

## 核心知识

- 事件循环、异步 I/O、Promise、流和错误处理。
- HTTP 服务、路由、中间件、请求校验和统一异常处理。
- 数据库访问、连接池、事务边界和迁移工具。
- 认证授权、日志、指标、链路追踪和配置管理。
- 进程管理、集群、容器化和优雅停机。

## 常见框架

- Express：轻量、生态成熟，适合快速 API 和中间件组合。
- Koa：更小的中间件核心，适合自定义能力强的项目。
- NestJS：模块化、依赖注入和 TypeScript 体验更完整，适合中大型服务。

## 开发流程

```mermaid
flowchart LR
  A[定义接口契约] --> B[实现路由和服务]
  B --> C[接入数据库和缓存]
  C --> D[补认证、日志和错误处理]
  D --> E[测试、部署和监控]
```

## 实践检查清单

- 是否统一请求校验、错误响应和日志格式。
- 异步错误是否被框架捕获，避免进程崩溃或静默失败。
- 数据库连接池、超时和事务边界是否明确。
- CPU 密集任务是否移到 Worker、队列或独立服务。
- 是否支持优雅停机，避免部署时中断请求。

## 案例

BFF 服务适合用 Node.js 聚合多个后端 API，并为前端返回页面模型。但如果需要大量图片处理或复杂计算，应放到专门任务队列或其他服务中。

## 常见误区

- 认为单线程意味着不能并发，或认为异步就不会阻塞。
- 忘记处理 Promise rejection，线上错误难追踪。
- 把所有逻辑写在路由回调里，后续测试和复用困难。
