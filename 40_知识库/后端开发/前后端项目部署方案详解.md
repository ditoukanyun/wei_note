## 一、单服务器部署方案

### 方案一：Nginx 反向代理（推荐）

#### 架构

```
用户请求 → Nginx ──┬─→ 前端静态文件 (localhost)
                   └─→ 后端 API (localhost:8080)
```

#### 项目结构

```
/var/www/
├── moss-web/          # 前端 Vue/React 项目
│   └── dist/
└── moss-api/          # 后端 Node/Java 项目
    └── app.js
```

#### Nginx 完整配置

```nginx
# /etc/nginx/sites-available/moss.cn

server {
    listen 80;
    server_name moss.cn;
    
    # ========== 1. 前端静态资源 ==========
    location / {
        root /var/www/moss-web/dist;
        index index.html;
        
        # 支持前端路由（Vue/React Router）
        try_files $uri $uri/ /index.html;
        
        # 缓存静态资源
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }
    
    # ========== 2. 后端 API 反向代理 ==========
    location /api/ {
        proxy_pass http://localhost:8080/;
        
        # HTTP 版本和连接升级
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        
        # 转发关键请求头
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
        
        # 缓存绕过
        proxy_cache_bypass $http_upgrade;
    }
    
    # ========== 3. WebSocket 支持（实时功能）==========
    location /ws/ {
        proxy_pass http://localhost:8080/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    # ========== 4. 上传文件大小限制 ==========
    client_max_body_size 50M;
}
```

#### 后端启动（Node.js 示例）

```bash
# 进入后端目录
cd /var/www/moss-api

# 安装依赖
npm install

# 方式 1：直接启动
node app.js

# 方式 2：使用 PM2 守护进程（推荐）
pm2 start app.js --name "moss-api" -- -p 8080

# PM2 常用命令
pm2 list              # 查看进程
pm2 logs moss-api     # 查看日志
pm2 restart moss-api  # 重启
pm2 stop moss-api     # 停止
```

### 方案二：Docker 容器化部署

#### 架构

```
用户 → Nginx (宿主机) ──┬─→ 前端容器 (nginx:alpine)
                        └─→ 后端容器 (node:18)
                               ↓
                        数据库容器 (mysql:8.0)
```

#### docker-compose.yml

```yaml
version: '3.8'

services:
    frontend:
        build: ./frontend
        container_name: moss-frontend
        restart: always
        networks:
            - moss-network
    
    backend:
        build: ./backend
        container_name: moss-backend
        environment:
            - NODE_ENV=production
            - PORT=3000
            - DB_HOST=mysql
        depends_on:
            - mysql
        restart: always
        networks:
            - moss-network
    
    nginx:
        image: nginx:alpine
        container_name: moss-nginx
        ports:
            - "80:80"
            - "443:443"
        volumes:
            - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
        depends_on:
            - frontend
            - backend
        restart: always
        networks:
            - moss-network
    
    mysql:
        image: mysql:8.0
        container_name: moss-mysql
        environment:
            - MYSQL_ROOT_PASSWORD=${DB_ROOT_PASSWORD}
            - MYSQL_DATABASE=${DB_NAME}
        volumes:
            - mysql-data:/var/lib/mysql
        restart: always
        networks:
            - moss-network

volumes:
    mysql-data:

networks:
    moss-network:
        driver: bridge
```

## 二、双服务器 Docker 部署方案

### 架构设计

```
                    ┌─────────────────────────┐
   用户访问         │      服务器 A            │
   ─────────→      │    (前端 + Nginx 网关)   │
  moss.cn          │                         │
                   │  ┌───────────────────┐  │
                   │  │  Nginx (Docker)   │  │
                   │  │  ├─ 前端静态文件   │  │
                   │  │  ├─ SSL 证书      │  │
                   │  │  └─ 反向代理配置   │  │
                   │  └───────────────────┘  │
                   └───────────┬─────────────┘
                               │ 内网/公网
                               ▼
                   ┌─────────────────────────┐
                   │      服务器 B            │
                   │    (后端 + 数据库)       │
                   │                         │
                   │  ┌───────────────────┐  │
                   │  │  Node API         │  │
                   │  │  (Docker)         │  │
                   │  └───────────────────┘  │
                   │  ┌───────────────────┐  │
                   │  │  MySQL            │  │
                   │  │  (Docker)         │  │
                   │  └───────────────────┘  │
                   │  ┌───────────────────┐  │
                   │  │  Redis            │  │
                   │  │  (Docker)         │  │
                   │  └───────────────────┘  │
                   └─────────────────────────┘
```

---

### 服务器 A：前端 + Nginx 网关

#### docker-compose.yml

```yaml
version: '3.8'

services:
    nginx:
        image: nginx:alpine
        container_name: moss-gateway
        ports:
            - "80:80"
            - "443:443"
        volumes:
            - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
            - ./nginx/conf.d:/etc/nginx/conf.d:ro
            - ./nginx/ssl:/etc/nginx/ssl:ro
            - ./frontend/dist:/usr/share/nginx/html:ro
        restart: always
        networks:
            - moss-net

networks:
    moss-net:
        driver: bridge
```

#### Nginx 配置

```nginx
# 上游服务器（服务器 B）
upstream backend_servers {
    server 192.168.1.100:8080;
    # 或公网 IP：server 118.145.223.122:8080;
}

server {
    listen 80;
    server_name moss.cn;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name moss.cn;
    
    ssl_certificate /etc/nginx/ssl/moss.cn.crt;
    ssl_certificate_key /etc/nginx/ssl/moss.cn.key;
    
    # 前端
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }
    
    # 后端 API
    location /api/ {
        proxy_pass http://backend_servers/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 服务器 B：后端 + 数据库

#### docker-compose.yml

```yaml
version: '3.8'

services:
    api:
        build: ./app
        container_name: moss-api
        ports:
            - "127.0.0.1:8080:3000"  # 仅内网访问
        environment:
            - NODE_ENV=production
            - PORT=3000
            - DB_HOST=mysql
            - DB_USER=${DB_USER}
            - DB_PASSWORD=${DB_PASSWORD}
            - DB_NAME=${DB_NAME}
            - REDIS_HOST=redis
        depends_on:
            - mysql
            - redis
        restart: always
        networks:
            - backend-net
    
    mysql:
        image: mysql:8.0
        container_name: moss-mysql
        environment:
            - MYSQL_ROOT_PASSWORD=${DB_ROOT_PASSWORD}
            - MYSQL_DATABASE=${DB_NAME}
            - MYSQL_USER=${DB_USER}
            - MYSQL_PASSWORD=${DB_PASSWORD}
        volumes:
            - ./data/mysql:/var/lib/mysql
        restart: always
        networks:
            - backend-net
    
    redis:
        image: redis:7-alpine
        container_name: moss-redis
        command: redis-server --appendonly yes --requirepass ${REDIS_PASSWORD}
        volumes:
            - ./data/redis:/data
        restart: always
        networks:
            - backend-net

networks:
    backend-net:
        driver: bridge
```

### 网络配置

#### 方案 1：内网互通（推荐）

```
服务器 A: 192.168.1.10  →  服务器 B: 192.168.1.100:8080
```

**安全组配置：**
- 服务器 B 只开放 8080 端口给服务器 A 的内网 IP
- 数据库端口不暴露到公网

#### 方案 2：公网访问

```
服务器 A: 通过公网 IP → 服务器 B: 118.145.223.122:8080
```

**注意：**
- 服务器 B 需要防火墙限制，只允许服务器 A 的 IP 访问
- 使用 HTTPS 加密通信

### 部署脚本

#### 服务器 A 部署脚本

```bash
#!/bin/bash
# deploy-frontend.sh

cd ~/moss-web
git pull origin main
npm ci
npm run build

rm -rf ~/moss-deploy/frontend/dist
cp -r dist ~/moss-deploy/frontend/

cd ~/moss-deploy
docker-compose restart nginx

echo "前端部署完成: $(date)"
```

#### 服务器 B 部署脚本

```bash
#!/bin/bash
# deploy-backend.sh

cd ~/moss-backend/app
git pull origin main

cd ~/moss-backend
docker-compose down
docker-compose up -d --build
docker image prune -f

echo "后端部署完成: $(date)"
```

## 三、方案对比与选择

| 方案 | 复杂度 | 适用场景 | 优点 | 缺点 |
|-----|--------|---------|------|------|
| **单服务器 Nginx** | ⭐ 低 | 小型项目、个人网站 | 简单、资源占用少 | 单点故障、扩展性差 |
| **单服务器 Docker** | ⭐⭐ 中 | 中小型项目、需要隔离 | 环境一致、易于迁移 | 资源开销稍大 |
| **子域名分离** | ⭐⭐ 中 | 前后端独立部署 | 职责清晰、可独立扩展 | 需要多台服务器 |
| **双服务器 Docker** | ⭐⭐⭐ 高 | 中大型项目、生产环境 | 高可用、安全、可扩展 | 复杂度高、成本高 |

### 选择建议

- **个人项目/博客** → 单服务器 Nginx
- **小型团队项目** → 单服务器 Docker
- **中大型项目** → 双服务器 Docker
- **需要独立扩展前后端** → 子域名分离
