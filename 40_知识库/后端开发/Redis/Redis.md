# Redis

## 定义

Redis 是一个高性能内存数据结构存储系统，常用于缓存、会话、计数器、排行榜、分布式锁、限流和消息相关场景。它速度快，但需要认真处理持久化、内存淘汰、高可用和数据一致性。

## 常用能力

- 字符串、哈希、列表、集合、有序集合等数据结构。
- TTL、过期淘汰和内存策略。
- 发布订阅、Stream、Lua 脚本和事务。
- 主从复制、哨兵和集群。

## 工程边界

- Redis 不应替代强一致主数据库。
- 缓存写入、失效和重建策略要结合业务一致性要求。
- Big Key、热点 Key 和慢查询需要持续治理。
