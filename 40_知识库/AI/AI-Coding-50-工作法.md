# AI Coding 50% 工作法

> 将 **50% 精力放在业务代码**，**50% 精力放在 Harness 环境优化** 上。

## 核心思想

AI Coding 时代，程序员的竞争力不再只是写代码的速度，而是**让 AI Agent 高效、自主、长时间运行**的能力。

这需要你在两个维度上分配精力：
- **业务交付** — 完成当前项目需求
- **Harness 优化** — 打造让 Agent 自主运行的环境

---

## 两种失衡状态

### 状态 1：时间被业务占满

**症状：**
- 并行跑 4 个任务，每个 Agent 不断问你问题
- 你在各个上下文之间疯狂切换，身心疲惫
- 一天下来感觉忙得要死，但产出一般

**根因：**
Agent 问你的问题通常属于以下三类：

| 问题类型 | 说明 | 解决方向 |
|---------|------|---------|
| 环境配置问题 | 执行总报错，缺少依赖、权限不足 | 完善 Harness 环境配置 |
| 业务知识缺口 | 不理解业务逻辑，需要补充背景 | 完善项目文档和 Context |
| 方向不确定 | 拿不准接下来做什么，需要指方向 | 优化任务拆解和计划 |

**解决方案：**
1. **降低并行度**：从 4 个任务降到 2 个
2. **释放出的 50% 精力投入 Harness 优化**：
   - 配置完善的开发环境（Docker、CI/CD、自动化脚本）
   - 编写详细的业务文档和项目 Context
   - 建立标准化的任务拆解模板
3. **持续迭代**：每解决一个 Harness 问题，Agent 的自主运行时间就延长一点

**演进路径：**
```
阶段 1: 4 任务并行，每 10 分钟问一次 → 精疲力尽
    ↓ (优化 Harness)
阶段 2: 2 任务并行，每 30 分钟问一次 → 游刃有余
    ↓ (持续优化)
阶段 3: 4 任务并行，每 2 小时问一次 → 高效且轻松
```

### 状态 2：时间去摸鱼

**症状：**
- Agent 在执行时，你把剩余 50% 精力拿去刷手机、看新闻
- 短期很爽，长期危险

**风险：**
> **能力退化陷阱**：既不会手写代码，也不会指挥 Agent

在 AI Coding 时代，手写代码的能力会自然退化（这是正常的），但**指挥 AI 的能力**必须持续精进：
- 需求拆解能力
- Prompt 工程能力
- 架构设计能力
- 代码审查能力
- Harness 优化能力

**解决方案：**
用释放出的 50% 精力做**有复利效应**的事：

| 投入方向 | 具体行动 | 长期收益 |
|---------|---------|---------|
| 学习新工具 | 研究 Cursor/Claude/Windsurf 的新特性 | 效率持续提升 |
| 打磨 Prompt | 建立个人 Prompt 库，持续优化 | 一次编写，永久复用 |
| 优化 Harness | 完善项目模板、自动化脚本 | 每个新项目都更快 |
| 知识沉淀 | 写 Wiki、做复盘、分享经验 | 建立个人知识资产 |
| 深度思考 | 研究业务架构、技术选型 | 提升决策质量 |

## AI 知识半衰期

> 当前及未来几年，新 AI 知识的**有效期只有 3～6 个月**，过了时间就不用学了（因为过时了）。

但关键在于：
- **如果你能快速学习**（1 个月内掌握）
- **你就能在接下来的 2～5 个月里**，比没学的同行效率高 N 倍

这就是 AI Coding 时代的**效率套利窗口**。

**策略：**
1. **快速学习，快速应用** — 不要等"学精通"再用，边用边学
2. **建立学习机制** — 每周固定时间了解新工具、新技巧
3. **选择性投入** — 不是所有新东西都值得学，评估 ROI

## 实践建议

### 每日时间分配示例

| 时间段 | 内容 | 占比 |
|-------|------|-----|
| 上午 | 深度业务开发（2-3 个任务并行） | 50% |
| 下午 | 业务收尾 + Harness 优化 | 30% |
| 晚上 | 学习新工具/沉淀知识 | 20% |

### 每周 Harness 优化清单

- [ ] 本周 Agent 问得最多的 3 个问题是什么？能否彻底解决？
- [ ] 是否有新的 AI 工具/特性值得尝试？
- [ ] 项目文档是否需要更新？
- [ ] 本周学到的技巧是否已沉淀到 Prompt 库？
- [ ] 自动化脚本是否还能进一步优化？

### 关键指标

追踪以下指标，评估你的 50% 工作法执行效果：

| 指标 | 说明 | 目标 |
|-----|------|-----|
| 平均任务自主运行时间 | Agent 从启动到第一次问问题的间隔 | > 1 小时 |
| 每日上下文切换次数 | 你回答 Agent 问题的次数 | < 10 次 |
| Harness 优化时间占比 | 每天投入环境优化的时间比例 | > 30% |
| 知识沉淀数量 | 每周新增的 Prompt/文档/脚本数量 | > 3 个 |
