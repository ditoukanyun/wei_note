# Agent 工具层

## 定义

Agent 工具层是 [[AI Agent Harness]] 中负责把模型意图转化为真实动作的部分。它定义工具能力、暴露参数模式、校验调用请求、执行工具、捕获结果，并把结果格式化为模型可理解的观察信息。

## 要点

- 工具是 Agent 的“手”，但工具选择和参数生成通常由模型完成。
- 工具层必须做结构化校验，不能把模型输出直接当作可信命令执行。
- 工具范围越小、描述越清晰，模型越容易做出正确选择。
- 高副作用工具需要结合 [[Agent 护栏]]、[[Sandbox]] 和人工确认。

## 工具层职责

- 注册工具名称、说明和参数 schema。
- 控制工具暴露范围，只提供当前任务需要的最小工具集。
- 执行前检查权限、路径、网络、密钥和成本边界。
- 执行后捕获标准输出、错误、变更文件和返回值。
- 将失败信息结构化返回，让模型有机会自我修复。

## 示例

文件编辑工具可以允许 Agent 修改项目文件，但工具层需要限制可写目录、记录 diff、拒绝访问密钥文件，并在删除或覆盖大量文件前请求确认。
