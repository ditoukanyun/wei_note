# 代码即事实来源

## 定义

代码即事实来源是指在软件系统中，把实际运行的代码、测试和配置视为最终事实，而不是把可能过期的设计文档当作事实源。

在 AI 编程环境中，这一点更重要，因为 Agent 可以直接读取代码、追踪调用关系，并基于真实实现回答问题或生成变更。

## 要点

- 文档容易与实现脱节，代码和测试更接近真实系统行为。
- 如果业务必须保留 spec，应把 spec 放进代码库，让工具检查文档与实现是否一致。
- 技术讨论可以从“看设计稿/文档”转向“看 PR 对系统产生的真实影响”。
- 代码作为事实来源不等于不要文档，而是文档必须可校验、可追踪、可更新。

## 实践方式

- 把需求、架构决策、接口契约和测试尽量纳入仓库版本控制。
- 用 Agent 检查代码与文档、测试、配置之间的不一致。
- 对技术客诉优先让工具从代码路径、日志和配置中定位事实。
- 减少不可执行、不可验证、无人维护的长文档。
