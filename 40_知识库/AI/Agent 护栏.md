# Agent 护栏

## 定义

Agent 护栏是在 [[AI Agent Harness]] 中限制输入、输出和工具执行风险的机制。它不假设模型永远正确，而是在模型行动前后用规则、权限、沙盒和人工确认控制副作用。

## 护栏类型

- 输入护栏：检查用户请求是否包含提示注入、敏感数据或违规目标。
- 工具护栏：在工具执行前检查权限、路径、网络、成本和副作用。
- 输出护栏：检查最终结果是否泄露隐私、违反格式或带来安全风险。
- 运行时护栏：限制执行时间、资源、重试次数和可访问环境。
- 人类护栏：对法律、合规、安全敏感和高影响动作保留确认权。

## 关键判断

- 模型负责“想做什么”，Harness 负责“允许做什么”。
- 护栏不是为了阻止 Agent 工作，而是为了让 Agent 可以在更大范围内安全工作。
- 权限应该按任务逐步授予，而不是默认全开。
- 工具副作用越强，越需要审计日志和回滚机制。

## 示例

代码 Agent 可以自动读取仓库和运行测试，但删除文件、修改部署配置、访问生产密钥或推送远端分支时，应触发更高等级确认。
