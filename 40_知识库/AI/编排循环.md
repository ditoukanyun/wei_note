# 编排循环

## 定义

编排循环是 [[AI Agent Harness]] 的核心执行循环，用来反复完成“组装上下文 -> 调用模型 -> 解析输出 -> 执行工具 -> 观察结果 -> 更新状态”的过程，直到任务完成或触发停止条件。

它常见的行为模式是 TAO：Thought、Action、Observation，也就是 [[AI相关/Agent架构/ReAct|ReAct]] 的工程化实现。

## 要点

- 循环本身通常很简单，复杂度来自状态、错误、权限、上下文和退出条件。
- 模型负责推理和选择动作，Harness 负责安全执行和回合管理。
- 每次工具调用都应该产生结构化观察结果，供模型继续决策。
- 循环必须有明确停止条件，避免无限重试、成本失控或副作用放大。

## 常见步骤

1. 组装系统提示词、工具定义、记忆和当前任务。
2. 调用模型，得到文本响应或工具调用请求。
3. 判断是否需要执行工具。
4. 校验工具参数和权限。
5. 执行工具并捕获输出或错误。
6. 将观察结果写回上下文。
7. 判断继续、完成、重试或升级给人。

## 示例

代码修复 Agent 收到 bug 描述后，先搜索相关文件，再读取代码，再修改文件，然后运行测试。如果测试失败，错误日志会作为观察结果回到下一轮循环；如果连续失败或涉及高风险文件，则暂停并请求人工判断。
