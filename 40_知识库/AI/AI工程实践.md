# AI工程实践
AI工程实践关注把模型能力稳定接入真实软件系统，包括评测、提示词管理、工具调用、可观测性、成本控制和安全边界。

```mermaid
  A[明确业务目标] --> B[选择模型和架构]
  B --> C[构建评测集]
  C --> D[接入工具和数据]
  D --> E[上线观测和迭代]
```

## 实践检查清单

- 是否定义准确率、延迟、成本、安全和用户体验指标。
- Prompt、模型版本、工具版本是否可追踪。
- 是否有离线评测和线上反馈闭环。
- 工具调用是否有权限、超时、重试和审计。
- 是否设计失败兜底、人工接管和风险提示。

## 案例

企业知识库助手上线前，应准备真实问题集，验证召回文档、答案引用和拒答策略。上线后继续收集低满意度问题，回流到评测集和知识库更新流程。

## 常见误区

- 只看演示效果，不建立可重复评测。
- 把模型输出直接写入业务系统，没有人工确认或回滚。
- 忽略成本和延迟，原型可用但生产不可承受。
