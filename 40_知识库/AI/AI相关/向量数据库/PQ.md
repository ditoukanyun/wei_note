# PQ
PQ 是 Product Quantization，乘积量化，用于压缩向量并降低大规模检索的存储和计算成本。

## 相关概念
- [[IVF]]
- [[ANN]]

## 工作流程

```mermaid
flowchart LR
  A[原始高维向量] --> B[切分为多个子向量]
  B --> C[对子空间聚类]
  C --> D[保存码本和编码]
  D --> E[用近似距离检索]
```

## 适用场景

- 向量规模很大，原始浮点向量存储成本过高。
- 可以接受一定召回损失，换取更低内存和更高吞吐。
- 常与 IVF 等索引结构组合，用于大规模 ANN 检索。

## 实践检查清单

- 是否用真实查询集评估召回率，而不是只看压缩比。
- 子向量数量和码本大小是否经过实验调参。
- 是否保留必要的原始向量或重排能力，提高最终精度。
- 是否监控不同数据分布下的召回退化。
- 是否明确压缩带来的精度损失能被业务接受。

## 常见误区

- 认为 PQ 只是无损压缩，忽略近似误差。
- 只优化存储，不评估检索质量。
- 在小规模数据上过早使用复杂压缩，增加系统复杂度。
