# Claude Code 进阶技巧
Claude Code 进阶技巧包括上下文管理、技能化、计划拆解、测试验证、Git 工作流和自动化协作。

## 相关概念
- [[Claude Code 配置详解]]
- [[Claude Code Skills 开发]]

## 使用流程

```mermaid
flowchart LR
  A[明确任务目标] --> B[收集上下文]
  B --> C[拆解计划]
  C --> D[执行修改]
  D --> E[验证和总结]
```

## 实践检查清单

- 是否先明确目标、约束和验收标准。
- 大任务是否拆成可验证的小批次。
- 是否优先读取现有文件和约定，而不是凭空生成。
- 修改后是否运行对应测试、格式检查或链接校验。
- 是否把重复工作沉淀为 Skill 或脚本。

## 案例

整理知识库时，可以先用脚本找短笔记，再分批补流程图、案例和误区，最后跑 wikilink 校验。这样比随机打开文件补内容更稳定。

## 常见误区

- 上来就让模型改大量文件，没有先建立扫描标准。
- 只看最终文本，不验证文件格式和链接完整性。
- 反复做同类任务却不沉淀可复用流程。
