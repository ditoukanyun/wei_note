# ETF T+0 交易检查清单

> 适用于盯盘1-2只ETF，偶尔可能错过行情的场景
> 核心理念：**条件单保底 + 手动优化**

---

## 📋 盘前准备（9:15-9:25）

### 标的筛选
- [ ] 选择当日重点跟踪的 **1-2只** ETF
- [ ] 查看对应指数隔夜走势和消息面
- [ ] 确认标的流动性（日成交额 > 1亿）

### 技术位预判
- [ ] 标记关键支撑位（昨日低点/均线/整数关口）
- [ ] 标记关键压力位（昨日高点/前高）
- [ ] 计算目标买卖点（按0.5%-1.5%档位）

## 💰 资金管理规则（以1万元为例）

> [!info] 核心原则：分仓操作，单笔不超过30%，一天最多3笔

### 资金分配

```
总资金：10,000元

单笔金额：3,000元（30%）
预留资金：1,000元（10%，防意外）
日内最大持仓：6,000元（两笔叠加，不重仓）
```

### 手续费计算

ETF交易费用：
- 佣金：万分之2.5（买卖都收，最低5元）
- 印花税：0（ETF免印花税）

单笔3000元交易成本：
- 买入：max(3000 × 0.025%, 5) = 5元
- 卖出：max(3000 × 0.025%, 5) = 5元
- **单笔总成本：10元**

> [!warning] 盈亏平衡点：10元利润才能保本，对应涨幅≥0.4%

### 盈亏控制标准

| 指标 | 数值 | 说明 |
|------|------|------|
| 单笔止盈 | ≥0.5%（15元） | 覆盖成本+有利润 |
| 单笔止损 | ≤0.5%（15元） | 单笔最大亏损控制 |
| 日最大亏损 | 60元（2%本金） | 连续亏4笔强制停手 |
| 日目标盈利 | 100元（1%本金） | 见好就收 |

### 操作示例

**第一笔（正常交易）**
```
10:00 买入：1.200 × 2500份 = 3,000元
10:05 设条件单：
  - 止损：1.194（-0.5%）→ 亏损15元
  - 止盈：1.210（+0.83%）→ 盈利25元
11:00 触发止盈，卖出
结果：+25元 - 4元（手续费）= +21元
```

**第二笔（阴跌止损）**
```
13:30 买入：1.150 × 2600份 = 2,990元
13:35 发现阴跌，立即止损：1.143
结果：-18元 - 4元（手续费）= -22元
纪律：当日不再操作，不补仓
```

### 资金管理铁律

- [ ] **单笔≤3000元**，不重仓赌一把
- [ ] **留1000元备用**，不全部打光
- [ ] **最多同时2笔**，保持流动性
- [ ] **日亏损≥60元**，立即停止
- [ ] **日盈利≥100元**，可考虑收工

### 新手建议（前两周）

1. **只用1000元试水**（单笔300-500元）
2. 熟悉条件单设置和交易节奏
3. 不追求盈利，只练执行力
4. 统计胜率，达到60%后再加大资金

## ⏰ 早盘阶段（9:30-10:00）

> [!warning] 开盘波动大，谨慎使用条件单

### 买入时操作
- [ ] **买入成交后30秒内**，启动条件单
- [ ] 先挂**止损单**（买入价-0.5%，硬性止损）
- [ ] 暂不设止盈，或设较高止盈（+1.5%以上）
- [ ] 密切观察开盘30分钟量价关系

### 开盘后30分钟
- [ ] 判断当日趋势（多头/空头/震荡）
- [ ] 趋势明确后，调整条件单参数
- [ ] 记录开盘高低点作为参考

## ☀️ 午盘阶段（10:00-14:30）

> [!tip] 趋势较稳，条件单主力运作时段

### 标准条件单配置

假设买入价：**X.XXX**

| 条件单类型    | 触发条件                       | 执行动作    | 用途    |
| -------- | -------------------------- | ------- | ----- |
| **止损单**  | 跌破 `X.XXX × 0.995`         | 市价卖出全部  | 保命底线  |
| **止盈单**  | 涨至 `X.XXX × 1.008`         | 限价卖出50% | 保底利润  |
| **回落止盈** | 涨超 `X.XXX × 1.015` 后回落0.3% | 卖出剩余50% | 让利润奔跑 |

### 手动干预时机
- [ ] **急拉时**：手动追加卖单，不等条件单
- [ ] **跌破均线**：手动减仓或清仓
- [ ] **放量滞涨**：撤掉止盈，提前离场

### 档位参考（按价格区间）

| ETF价格 | 最小档位  | 建议止盈档位       | 建议止损档位 |
| ----- | ----- | ------------ | ------ |
| < 1元  | 0.001 | +0.003~0.005 | -0.003 |
| 1-2元  | 0.001 | +0.005~0.008 | -0.005 |
| 2-3元  | 0.001 | +0.008~0.012 | -0.008 |
| > 3元  | 0.001 | +0.010~0.015 | -0.010 |

## 🌆 尾盘阶段（14:30-15:00）

> [!danger] 时间紧迫，必须成交，不留隔夜

### 买入后操作（14:30后买入）
- [ ] **降低预期**：止盈设为+0.5%~+0.8%
- [ ] **严格止损**：-0.3%~-0.5%立即执行
- [ ] **取消回落止盈**：时间不够，见好就收

### 清仓检查（14:50）
- [ ] 检查是否还有持仓
- [ ] **未成交的全部手动市价卖出**
- [ ] 确认当日无隔夜仓

## 🎯 条件单设置模板

### 买入价示例：1.200

```
【第一层：保命单】必设
□ 止损单：跌破 1.194 (-0.5%)，市价卖出 100%
□ 止盈单：涨至 1.210 (+0.83%)，限价 1.209 卖出 50%

【第二层：优化单】选设
□ 回落止盈：涨超 1.218 (+1.5%) 后回落 0.3%，卖出剩余 50%
□ 网格卖出：1.206(+0.5%)卖30%、1.212(+1%)卖30%、1.218(+1.5%)卖40%
```

### 快速计算表

|--------|----------|----------|----------|
| 1.000 | 0.995 | 1.008 | 1.015 |
| 1.100 | 1.094 | 1.109 | 1.117 |
| 1.200 | 1.194 | 1.210 | 1.218 |
| 1.500 | 1.493 | 1.512 | 1.523 |
| 2.000 | 1.990 | 2.016 | 2.030 |

## ⚠️ 纪律红线

> [!failure] 以下情况必须无条件执行

- [ ] **止损触发立即走**，不补仓、不犹豫
- [ ] **尾盘14:50必须清仓**，不过夜、不赌消息
- [ ] **单只ETF亏损>1%**，当日停止交易该标的
- [ ] **连续2笔亏损**，当日停止T+0操作

### 阴跌处理（重要！）

> [!danger] **阴跌时绝对不要补仓，只挂止损单**

**阴跌识别**（买入后30分钟内）：
- 5分钟内没有向上攻击
- 价格被均线压制
- 每波反弹高点低于前高
- 买盘稀少，小阴线排列

**正确操作**：
- 立即挂市价或低于现价0.2-0.3档卖出
- 目标：尽快脱身，不在乎多卖1-2档
- 亏损确认后，当日不再操作
