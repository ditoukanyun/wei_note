# ETF 波段交易检查清单

> 适用于不能长时间盯盘、追求胜率而非频率的交易者
> 核心理念：**低频高胜率 + 条件单自动执行 + 绝不补仓**

---

## 🎯 交易原则（先背熟）

> [!danger] 不可违反的铁律
> 1. **亏损绝不补仓** —— 错了就认，摊低成本是毒药
> 2. **触发止损立即走** —— 不看感觉，只看数字
> 3. **一周最多2笔** —— 没机会就等，不强行交易
> 4. **收盘前必须清仓** —— 波段不留隔夜（除非明确趋势持仓）

---

## 📅 周末选股（每周六日）

### 选股标准（5条必须全满足）

- [ ] **趋势向上**：20日均线向上，价格在均线之上
- [ ] **有清晰支撑**：能画出明确的支撑位（均线/前低/平台）
- [ ] **不在高位**：从近期低点涨幅 < 20%
- [ ] **流动性好**：日成交额 > 2亿元
- [ ] **波动适中**：近20日平均振幅 1.5%-3%

### 标记关键价位

```
示例：某ETF当前价格 1.200

支撑位：1.150（前期平台低点）
压力位：1.280（前期高点/整数关口）
买入区：1.155-1.165（支撑位上方1-2档）
止损位：1.130（支撑位下方2%，硬性止损）
第一止盈：1.240（+6%）
第二止盈：1.280（+10%）
```

### 快速计算表

| 买入价 | 止损(-2%) | 一止盈(+6%) | 二止盈(+10%) | 盈亏比 |
|--------|-----------|-------------|--------------|--------|
| 1.000 | 0.980 | 1.060 | 1.100 | 3:1 |
| 1.100 | 1.078 | 1.166 | 1.210 | 3:1 |
| 1.200 | 1.176 | 1.272 | 1.320 | 3:1 |
| 1.500 | 1.470 | 1.590 | 1.650 | 3:1 |
| 2.000 | 1.960 | 2.120 | 2.200 | 3:1 |

### 确定下周交易标的

- [ ] 选出 **1-2只** ETF 放入观察池
- [ ] 每只标注：买入区、止损位、止盈位
- [ ] 记录选股理由（技术面/基本面）
- [ ] 准备条件单参数

> [!warning] 如果找不到符合条件的标的
> **空仓等待**，宁可错过不做错

## 💰 资金管理规则

### 仓位分配（以1万元为例）

```
总资金：10,000元

单只ETF最大仓位：5,000元（50%）
同时持仓上限：1只（另一只作为备选）
预留现金：5,000元（等更好机会或应急）

单笔最大亏损：250元（本金的2.5%）
单日最大亏损：250元（一笔亏完就停）
```

### 建仓策略

```
第一次买入：计划仓位的 60%（3000元）
第二次买入：计划仓位的 40%（2000元）—— 仅当第一次买入后价格上涨1%以上

绝不补仓摊低成本！
如果买入后下跌，触发止损就走，不补第二笔。
```

### 手续费计算

ETF交易费用：
- 佣金：万分之2.5（最低5元）
- 印花税：0（ETF免印花税）

单笔5000元交易成本：
- 买入：max(5000 × 0.025%, 5) = 5元
- 卖出：max(5000 × 0.025%, 5) = 5元
- **单笔总成本：10元**

> [!tip] 盈亏平衡点：涨幅需覆盖0.2%成本

## 🏁 周一开盘前（9:15-9:25）

### 检查事项

- [ ] 隔夜消息面是否有重大变化（美股、政策）
- [ ] 观察标的是否跳空低开/高开（调整买入策略）
- [ ] 确认条件单是否正常挂出

### 条件单设置

**买入条件单（限价触发）**

```
触发条件：价格 ≤ 买入区上限
买入价格：买入区中位价
买入数量：计划仓位的60%
有效期：本周有效（周五收盘前失效）
```

**示例**：
```
买入区：1.155-1.165
条件单设置：
- 触发价：1.165
- 买入价：1.162（限价）
- 数量：2500份（约2900元）
- 有效期：5个交易日
```

> [!info] 如果开盘直接上涨超过买入区
> 取消本周交易，等待回调或换备选标的

## 📊 持仓阶段（买入后）

### 买入后30分钟内必须完成

- [ ] **设置硬性止损单**：跌破止损位，市价卖出 **100%**
- [ ] **设置第一止盈单**：涨至第一止盈位，卖出 **50%**
- [ ] **设置第二止盈单**：涨至第二止盈位，卖出 **50%**（或回落止盈）

**条件单配置示例**：
```
买入价：1.160

【保命单】必设
□ 止损单：跌破 1.130（-2.6%），市价卖出 100%
  → 最大亏损：3000×2.6% + 手续费 ≈ 85元

【利润单】必设  
□ 第一止盈：涨至 1.230（+6%），限价卖出 50%
  → 盈利：1500×6% - 手续费 ≈ 85元

【让利润奔跑】选设
□ 第二止盈：涨至 1.276（+10%），卖出剩余50%
  或：回落止盈（涨超1.280后回落1%，卖出剩余）
```

### 每日检查（可选，午休时快速看一眼）

- [ ] 条件单是否正常（是否误触发/失效）
- [ ] 持仓盈亏情况（只看是否触发，不纠结数字）
- [ ] 是否需要调整止盈位（上移止损保护利润）

### 上移止损规则（保护利润）

```
当盈利达到 +4% 时：
→ 将止损位上移至成本价（保本）

当盈利达到 +8% 时：
→ 将止损位上移至 +4%（锁定部分利润）

操作：手动修改条件单，或设置新的条件单
```

> [!warning] 禁止行为
> - 盈利时提前手动卖出（除非到达止盈位）
> - 亏损时取消止损单
> - 下跌时补仓摊低成本
> - "再看看"、"等反弹"

## 🌆 周五收盘前（14:50-15:00）

### 周末清仓检查

- [ ] 检查是否还有持仓
- [ ] **如有持仓，全部市价卖出**
- [ ] 确认无隔夜仓（波段不过周，除非明确趋势持仓）

> [!danger] 不过夜原则
> 除非确定是趋势性行情，否则波段交易周五收盘前必须清仓
> 目的是：规避周末消息面风险

### 每周回顾

- [ ] 本周交易次数（目标≤2次）
- [ ] 胜率统计（目标≥60%）
- [ ] 平均盈亏比（目标≥2:1）
- [ ] 最大单笔亏损（是否超2.5%本金）
- [ ] 是否有违规操作（补仓/取消止损等）

### 每月总结

- [ ] 月度收益率（目标3-5%）
- [ ] 统计各ETF表现，优化选股标准
- [ ] 检查条件单触发率
- [ ] 调整参数（如有必要）

## ⚠️ 纪律红线

> [!failure] 违反任意一条，停止交易一周

- [ ] **亏损绝不补仓** —— 错了就认，摊低成本是毒药
- [ ] **止损触发立即走** —— 不犹豫、不等待、不看盘
- [ ] **没到止盈不卖** —— 克服"落袋为安"心理
- [ ] **一周最多2笔** —— 没机会就空仓
- [ ] **周五必须清仓** —— 不留隔夜风险
- [ ] **单笔亏损≤2.5%本金** —— 保护本金第一
