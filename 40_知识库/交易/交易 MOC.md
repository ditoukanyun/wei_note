# 交易 MOC

交易目录用于沉淀交易方法、检查清单、心理建设和复盘规则。当前主线是“交易前计划 -> 执行检查 -> 风险控制 -> 复盘迭代”。

## 交易前计划

- 明确交易品种、周期和触发条件。
- 先判断趋势、支撑位、压力位和风险收益比。
- 只在条件满足时执行，不用临盘情绪替代计划。

## 使用方法

- 开盘前先看交易计划和检查清单。
- 交易中只执行已定义条件。
- 收盘后用复盘模板补记录，避免只记录结果、不记录决策过程。
