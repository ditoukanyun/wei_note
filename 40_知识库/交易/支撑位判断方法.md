# ETF T+0 支撑位判断方法

> 支撑位的准确判断是T+0交易成功的基础
> 核心原则：**多周期共振 + 量能确认**

---

## 📊 支撑位的本质

### 什么是支撑位
支撑位是价格下跌时**买盘力量≥卖盘力量**的价位，价格在此位置容易止跌反弹。

### 支撑位形成的原因
1. **心理关口**：整数价格、历史高低点
2. **成本密集区**：大量成交累积的筹码
3. **技术共振**：均线、趋势线、形态重合
4. **资金护盘**：主力或机构托单

## ⏱️ 多周期支撑体系

### 1分钟线（超短参考）
```
适用：决定精确买卖点
特点：波动快，噪音多

关键信号：
- 连续3根K线在同一价位止跌
- 快速下跌后出现长下影线
- 成交量突然萎缩（抛压枯竭）
```

### 5分钟线（主要周期）
```
适用：判断日内主趋势支撑
特点：平衡灵敏度与稳定性

关键信号：
- MA5/MA10均线支撑
- 前一根K线低点
- 开盘价的回踩确认
```

### 15分钟线（趋势判断）
```
适用：确认日内大趋势
特点：过滤杂波，看方向

关键信号：
- MA20均线（日内生命线）
- 前期震荡平台下沿
- 第一根15分钟K线低点
```

### 日线（大背景）
```
适用：判断日内交易是否值得做
特点：看大做小

关键信号：
- 昨日收盘价
- 昨日低点/近期低点
- 整数关口（如1.000、1.500）
```

## 🎯 六大支撑类型（按重要性排序）

### 1. 均线支撑（最常用）

**5分钟均线体系**
| 均线 | 作用 | 适用场景 |
|------|------|----------|
| MA5 | 强势支撑 | 主升浪中的回踩买点 |
| MA10 | 常规支撑 | 趋势延续时的买入点 |
| MA20 | 生命线 | 跌破则趋势转弱，必须止损 |

**判断方法**：
- 价格回踩均线时**缩量**→支撑有效，可买
- 价格跌破均线后**反弹不过**→支撑变压力，必须走
- 均线斜率**向上**→支撑强；**走平/向下**→支撑弱

### 2. 整数关口支撑

```
心理价位：0.500、1.000、1.500、2.000等

特点：
- 自动吸引买盘挂单
- 跌破后心理防线崩溃
- 适合设置条件单买入

操作要点：
- 1.000元附近往往有强支撑
- 跌破整数关口0.3%必须止损
- 反弹不过整数关口是卖出信号
```

### 3. 前期低点支撑

**昨日低点**
- 最直观的支撑位
- 跌破意味着弱势延续
- 未跌破可尝试低吸

**日内低点**
- 早盘创出的低点
- 二次回踩不破可买
- 跌破则日内趋势转空

**近期平台低点**
- 近3-5个交易日的低点连线
- 支撑力度最强
- 适合波段型ETF（如纳指ETF）

### 4. 分时均价线支撑

```
分时图中黄色均价线 = 当日平均成本

支撑有效信号：
✓ 价格在均价线上方运行，回踩不破
✓ 跌破后快速收复
✓ 均价线斜率向上

支撑失效信号：
✗ 价格持续在均价线下方运行
✗ 跌破后反弹不过均价线
✗ 均价线斜率向下
```

### 5. 量能支撑（关键确认）

**缩量止跌**（最佳买点）
```
特征：
- 价格下跌，成交量明显萎缩
- 较前一交易日缩量30%以上
- K线出现下影线或十字星

原理：抛压枯竭，随时可能反弹
操作：回踩支撑位+缩量=买入信号
```

**放量止跌**（次优买点）
```
特征：
- 价格快速下跌后放量回升
- 出现长下影线或锤子线
- 成交量是均量的2倍以上

原理：有资金主动承接
操作：确认放量阳线后买入
```

### 6. 盘口托单支撑

**识别方法**：
- Level2行情看买卖十档
- 某一价位出现大单托底
- 大单被吃后迅速补单

**注意事项**：
⚠️ 托单可能被突然撤掉（诱多）
⚠️ 不要只看盘口，要结合K线形态
⚠️ 大单托单+缩量=真支撑

## 🔍 支撑位强度判断

### 强支撑（可重仓买）
- [ ] 多周期共振（日线+15分钟+5分钟）
- [ ] 均线多头排列，斜率向上
- [ ] 缩量回踩，成交量萎缩50%以上
- [ ] 整数关口或前期平台低点
- [ ] 分时图有连续大单托底

### 中等支撑（轻仓试水）
- [ ] 两个周期共振（如5分钟+15分钟）
- [ ] 均线走平或微向上
- [ ] 成交量正常或略缩
- [ ] 盘中临时形成的低点

### 弱支撑（观望或放弃）
- [ ] 单一周期支撑
- [ ] 均线向下，价格被压制
- [ ] 放量下跌，成交量放大
- [ ] 无整数关口或关键价位配合

---

## ⚠️ 假支撑识别（避免陷阱）

### 假支撑特征
1. **时间太短**：只支撑了1-2根K线就跌破
2. **无量反弹**：价格反弹但成交量萎缩
3. **均线压制**：反弹不过MA5/MA10
4. **大盘拖累**：对应指数持续走弱

### 假支撑案例
```
错误操作：
10:00 价格跌到1.200，看似有支撑
10:05 买入
10:15 继续跌到1.190，跌破支撑
结果：被套

正确做法：
等待第二个低点确认（双底）
或等待放量阳线确认支撑有效
```

## 📈 实战支撑判断 Checklist

### 买入前检查（必须全部满足）
- [ ] **多周期确认**：5分钟+15分钟都有支撑信号
- [ ] **位置判断**：位于昨日低点/整数关口/均线之上
- [ ] **量能确认**：缩量回踩或放量止跌
- [ ] **大盘配合**：对应指数没有破位下跌
- [ ] **时间窗口**：不在14:30之后（尾盘风险高）

### 买入后验证（5分钟内判断对错）
- [ ] 买入后能否快速脱离成本区（5分钟内脱离0.2%以上）
- [ ] 是否出现止跌K线形态（阳线、十字星）
- [ ] 成交量是否配合（不再放量下跌）
- [ ] 如不符合，立即止损，不要等

## 🎯 不同场景的支撑策略

### 场景1：开盘跳空低开
```
策略：观察30分钟，不急于抄底

支撑位选择：
- 昨日收盘价（回补缺口）
- 昨日低点
- 整数关口

操作要点：
- 低开后横盘30分钟不创新低→可试买
- 低开低走放量→放弃，不抄底
```

### 场景2：冲高后回落
```
策略：找支撑位低吸

支撑位选择：
- 分时均价线
- 5分钟MA10
- 第一波上涨起点

操作要点：
- 缩量回落是买点
- 放量回落是卖点
- 14:00后不低吸（时间不够）
```

### 场景3：横盘震荡
```
策略：箱体下沿买，上沿卖

支撑位：箱体下沿
压力位：箱体上沿

操作要点：
- 严格执行箱体策略
- 跌破下沿立即止损
- 不要臆测突破
```

## 🔗 与条件单结合的支撑策略

### 预埋买入单
```
在关键支撑位挂限价买入单：
- 昨日低点下方0.2-0.3档
- 整数关口（如0.999、1.499）
- 5分钟MA10均线价位

好处：不用盯盘，自动成交
注意：要设好止损单配套
```

### 支撑位的止损设置
```
买入后止损位选择：
- 保守：支撑位下方0.3%
- 激进：支撑位下方0.5%
- 绝对：跌破支撑位不收回立即走

例如：1.200支撑位买入
- 保守止损：1.196（-0.33%）
- 激进止损：1.194（-0.5%）
```

> [!tip] 支撑位的核心心法
> 
> **支撑位不是绝对的，是概率的**
> - 强支撑：70%概率反弹 → 可买
> - 中支撑：50%概率反弹 → 轻仓
> - 弱支撑：30%概率反弹 → 放弃
> 
> **关键：支撑失效立即走，不要幻想**

## 实践检查清单

- 支撑位是否来自多次触碰、成交密集区或重要均线，而不是主观画线。
- 当前价格距离支撑位是否有足够安全边际。
- 入场前是否已经写好止损位和仓位。
- 跌破支撑后是否按规则退出，而不是临时改口径。
- 复盘时是否记录支撑位强弱和实际反应。

## 案例复盘

若 ETF 在 1.200 附近多次放量反弹，可把 1.200 视为候选支撑。第一次接近时只轻仓试探，若跌破 1.196 且无法收回，应执行止损；若放量反弹再确认，可考虑按计划做 T0。
