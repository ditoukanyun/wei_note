## 项目案例

电商商品页可以把商品基础信息、类目和标签缓存到 Redis，读取时先查缓存，未命中再回源数据库。上线前需要补齐随机 TTL、空值缓存、热点商品预热和回源限流，否则在促销流量下容易引发 [[缓存击穿]] 或 [[缓存雪崩]]。
