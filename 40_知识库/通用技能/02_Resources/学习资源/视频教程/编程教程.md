# 编程教程
编程教程用于沉淀视频课程、实战演示和学习路径。

## 相关概念
- [[持续学习]]

## 学习流程

```mermaid
flowchart LR
  A[选择课程] --> B[快速预览目录]
  B --> C[跟做核心章节]
  C --> D[独立复现项目]
  D --> E[整理知识点]
```

## 实践检查清单

- 课程是否有明确项目产出或练习。
- 是否控制倍速和笔记节奏，避免只看不练。
- 关键代码是否能脱离视频独立写出。
- 是否把课程知识拆成可复用的原子笔记。
- 是否用真实项目验证课程方法。

## 案例

看 React 项目教程时，不只记录组件写法，还要复盘路由、请求、权限、测试和部署链路，并连接到 [[React 项目实战]]。

## 常见误区

- 看完视频产生“我会了”的错觉，但不能独立实现。
- 复制课程代码，不理解环境和依赖。
- 不整理问题清单，遇到相同错误反复搜索。

## 复盘问题

- 课程结束后是否能不看视频独立复现核心功能。
- 遇到报错时是否能解释环境、依赖、代码和数据之间的关系。
- 课程内容是否已经拆成知识库笔记、项目练习或可复用代码片段。

## 输出标准

一门编程教程只有在形成“可运行项目、问题清单、概念笔记、复盘结论”之后，才算真正进入知识库。观看过程中可以记录时间戳和关键命令，但最终沉淀时要改写成自己的判断：这个技术解决什么问题、适用什么场景、有哪些前置知识、在真实项目里会踩哪些坑。若课程只是提供 API 用法，至少补一个独立小练习；若课程覆盖完整项目，则需要把架构、状态管理、接口设计、部署和测试分别拆出来，避免整门课只留一个泛泛的资源入口。

## 使用边界

视频教程适合作为入门引导和操作演示，不适合作为长期唯一依据。涉及版本、API、部署和安全配置时，需要回到官方文档或本地实验确认。
