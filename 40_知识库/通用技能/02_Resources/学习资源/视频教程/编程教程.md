# 编程教程
编程教程用于沉淀视频课程、实战演示和学习路径。

## 学习流程

```mermaid
flowchart LR
  A[选择课程] --> B[快速预览目录]
  B --> C[跟做核心章节]
  C --> D[独立复现项目]
  D --> E[整理知识点]
```

## 实践检查清单

- 课程是否有明确项目产出或练习。
- 是否控制倍速和笔记节奏，避免只看不练。
- 关键代码是否能脱离视频独立写出。
- 是否把课程知识拆成可复用的原子笔记。
- 是否用真实项目验证课程方法。

## 案例

看 React 项目教程时，不只记录组件写法，还要复盘路由、请求、权限、测试和部署链路，并连接到 [[React 项目实战]]。

## 常见误区

- 看完视频产生“我会了”的错觉，但不能独立实现。
- 复制课程代码，不理解环境和依赖。
- 不整理问题清单，遇到相同错误反复搜索。
