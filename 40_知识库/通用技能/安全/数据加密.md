# 数据加密
数据加密通过算法保护传输或存储中的敏感数据，常见场景包括 HTTPS、密码哈希和字段加密。

## 相关概念
- [[SSL/TLS]]
- [[API 安全基础]]

## 常见类型

- 传输加密：用 TLS 保护网络传输过程。
- 存储加密：数据库、磁盘或对象存储中的敏感数据加密。
- 密码哈希：密码不应可逆加密，而应使用带盐的慢哈希。
- 字段加密：对身份证、银行卡等敏感字段单独加密和脱敏展示。

## 处理流程

```mermaid
flowchart LR
  A[识别敏感数据] --> B[选择加密或哈希方式]
  B --> C[管理密钥和盐]
  C --> D[最小化解密入口]
  D --> E[审计访问记录]
```

## 实践检查清单

- 密钥是否由专门系统或环境变量管理，避免写入代码仓库。
- 是否区分可逆加密和不可逆哈希。
- 加密前后是否仍满足查询、排序和脱敏展示需求。
- 解密操作是否有权限控制和审计。
- 是否设计密钥轮换和历史数据重加密策略。

## 常见误区

- 自己设计加密算法，而不是使用成熟标准库。
- 把密钥和密文放在同一个数据库或配置文件中。
- 用普通哈希存密码，没有盐和慢哈希。
