# 函数式编程

## 定义

函数式编程是一种以函数作为主要抽象、强调组合、不可变数据和无副作用计算的编程范式。前端中它常用于数组转换、状态更新、选择器、Hook 组合和数据流处理。

## 要点

- 纯函数在相同输入下总是返回相同输出。
- 不可变数据让状态变化更容易追踪和测试。
- 高阶函数可以接收函数或返回函数。
- 组合优先于共享可变状态。

## 数据流

```mermaid
flowchart LR
    A["输入数据"] --> B["纯函数 transform"]
    B --> C["新数据"]
    C --> D["组合下一个函数"]
    D --> E["最终结果"]
```

函数式编程强调把数据转换拆成可组合的小函数，减少隐藏状态和副作用。

## 示例

```javascript
const total = orders
  .filter((order) => order.status === "PAID")
  .map((order) => order.amount)
  .reduce((sum, amount) => sum + amount, 0);
```

这里每一步都表达一个明确转换：过滤已支付订单、提取金额、求和。

## 检查清单

- 函数是否尽量依赖输入参数，而不是外部可变变量。
- 是否避免在 `map`、`filter` 中修改原数组。
- 是否把复杂流程拆成可命名的小函数。
- 是否在需要副作用时把副作用集中在边界层。

## 常见误区

- 为了“函数式”写出过度嵌套的链式调用，反而降低可读性。
- 在 `map` 里修改原对象，表面是函数式，实际仍有副作用。
- 忽略异常处理和调试成本。
- 把所有逻辑都抽成小函数，但没有表达业务含义的命名。

## 实践建议

前端状态更新、数据格式化、选择器计算适合用函数式思路；涉及 DOM 操作、网络请求、日志上报等副作用时，应把副作用放在边界层，让核心数据转换保持纯粹。
