# 原型链

## 定义

原型链是 JavaScript 对象属性查找和继承的机制。当访问对象属性时，引擎先查对象自身，再沿内部原型逐级向上查找，直到 `null`。

## 要点

- 构造函数的 `prototype` 会成为实例的原型。
- `Object.prototype` 通常位于普通对象原型链顶端。
- 原型链过深会增加理解成本，也可能造成属性遮蔽问题。
- class 语法本质上仍建立在原型机制之上。
