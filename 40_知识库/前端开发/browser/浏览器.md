# 浏览器

## 定义

浏览器是 Web 应用的运行环境，负责网络请求、HTML/CSS/JavaScript 解析、渲染、事件处理、安全隔离和存储能力。

## 要点

- 渲染流程包括解析、样式计算、布局、绘制和合成。
- JavaScript 在主线程运行，长任务会影响交互响应。
- 同源策略、CORS、Cookie 和 CSP 构成重要安全边界。
- 性能优化需要同时关注网络、渲染、脚本和资源缓存。
