# React 项目实战

React 项目实战是把组件、状态、路由、请求、权限、测试、构建和部署组合为完整应用的练习。

## 实战路径

```mermaid
flowchart LR
  A[搭建项目] --> B[设计路由和布局]
  B --> C[封装请求和状态]
  C --> D[实现业务页面]
  D --> E[测试、构建和部署]
```

## 实践检查清单

- 是否有清晰的目录结构和模块边界。
- 请求层是否统一处理认证、错误、超时和取消。
- 组件是否按页面、业务组件和基础组件拆分。
- 是否覆盖登录、权限、空态、错误态和加载态。
- 构建产物是否能在目标部署环境正确运行。

## 案例

做一个后台管理项目时，先实现登录、路由守卫、列表查询、表单编辑和错误处理，再补测试和部署。不要一开始就沉迷复杂组件库封装。

## 常见误区

- 只做页面静态效果，忽略接口契约和异常状态。
- 状态管理过早全局化，导致简单页面也难维护。
- 没有端到端验证，部署后才发现路由或环境变量问题。
