# localStorage

## 定义

localStorage 是浏览器提供的同步键值存储 API，数据可长期保存在同源站点下，常用于保存非敏感偏好设置。

## 要点

- API 是同步的，频繁大数据读写会阻塞主线程。
- 不适合保存高敏感 Token。
- 只能存字符串，复杂对象需要序列化。

## 实践检查清单

- 是否只保存非敏感、小体积、低频变更的数据。
- 读取时是否处理 JSON 解析失败和旧版本数据。
- 写入是否节流，避免频繁阻塞主线程。
- 是否设计清理和版本迁移策略。
- 是否理解同源限制和多标签页同步问题。

## 案例

主题色、侧边栏折叠状态和表格列宽适合保存到 localStorage。登录 Token、银行卡号和大量列表数据不适合保存。

## 使用边界

localStorage 的优点是简单持久，缺点是同步、容量有限且容易被 XSS 影响。它适合保存用户偏好和可重建状态，不适合保存高敏感凭证、频繁变化的大对象或需要事务一致性的业务数据。

读取时要把本地数据当作不可信输入处理。字段可能来自旧版本、手工修改或损坏 JSON，因此应做解析保护、schema 校验和默认值回退。跨标签页同步时还要监听 storage 事件，避免状态不一致。

如果状态会影响权限、价格或业务结果，最终判断必须回到服务端，不能信任 localStorage 中的值。

## 常见误区

- 把 localStorage 当安全存储。
- 不做版本兼容，字段变化后旧数据导致页面报错。
- 高频写入大对象，造成明显卡顿。
