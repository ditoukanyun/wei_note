# Apollo Client

## 定义

Apollo Client 是 GraphQL 客户端状态管理和数据获取库，负责发送查询、缓存规范化数据、管理加载/错误状态，并支持本地状态和乐观更新。

## 要点

- 适合 GraphQL API 和复杂对象图数据。
- 规范化缓存可以按实体 ID 合并和更新结果。
- Schema、Query 和缓存策略需要协同设计。
