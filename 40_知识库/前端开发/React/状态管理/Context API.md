# Context API

## 定义

Context API 是 React 内置的跨组件层级传值机制，适合主题、语言、当前用户、权限等低频变化的全局上下文。

## 要点

- Context 解决的是跨层级传递，不等同于完整状态管理框架。
- Provider 的 value 变化会影响消费者组件渲染，需要控制引用稳定性。
- 高频、复杂、可派生的状态通常更适合专门状态库或局部状态。
