## 实践检查清单

- 是否先掌握组件、props、state、effect 和事件处理。
- 状态管理是否从本地状态开始，再评估全局方案。
- 性能优化是否基于 Profiler 证据。
- 项目实践是否包含接口、路由、权限、测试和部署。
- 源码学习是否服务于理解实际问题，而不是孤立背诵。

## 案例

学习 React 后台项目时，可以先做列表和表单，再加入路由、请求封装、权限守卫、测试和构建部署，最后再深入并发特性和源码调度。

## 常见误区

- 一开始就学习源码，缺少真实项目问题支撑。
- 状态管理工具学很多，但组件边界仍然混乱。
- 只做页面样式，不处理异常态和测试。
