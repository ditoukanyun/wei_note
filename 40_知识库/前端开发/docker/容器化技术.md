# 容器化技术

容器化技术把应用及其依赖封装到隔离运行环境中，提升本地开发、测试和部署的一致性。

## 相关概念

- [[Docker]]
- [[docker-镜像]]

## 工作流程

```mermaid
flowchart LR
  A[编写 Dockerfile] --> B[构建镜像]
  B --> C[运行容器]
  C --> D[配置网络和卷]
  D --> E[推送镜像并部署]
```

## 实践检查清单

- 镜像是否固定基础版本并尽量精简。
- 配置、密钥和数据是否与镜像分离。
- 容器是否具备健康检查和日志输出。
- 本地、测试、生产是否使用一致的启动方式。
- 是否明确有状态服务的数据卷和备份策略。

## 案例

前端应用可以先用 Node 镜像构建静态产物，再复制到 Nginx 镜像中运行。最终运行镜像只包含静态资源和 Nginx，体积更小、攻击面更低。

## 常见误区

- 把容器当虚拟机，在容器内手工安装和修改。
- 把密钥写进镜像，推送后难以收回。
- 没有理解数据卷，重建容器时丢失数据。
