# TypeScript tsconfig 配置详解

## 定义

`tsconfig.json` 是 TypeScript 项目的编译配置文件，用于定义目标版本、模块系统、类型检查严格度、路径别名和输出行为。

## 常见配置

- `target`：输出 JavaScript 语法版本。
- `module`：模块格式。
- `strict`：启用严格类型检查。
- `paths`：配置路径别名。
- `noEmit`：只做类型检查，不输出文件。
