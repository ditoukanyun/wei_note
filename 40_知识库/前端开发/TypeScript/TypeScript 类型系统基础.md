# TypeScript 类型系统基础

## 定义

TypeScript 类型系统在 JavaScript 之上增加静态类型检查，帮助开发者在编译期发现字段、函数、联合类型和模块边界错误。

## 要点

- 基础类型包括 string、number、boolean、array、tuple、enum、unknown、never。
- interface 和 type 都能描述对象结构。
- 联合类型和类型收窄是业务建模核心能力。
- 类型服务于边界表达，不应追求过度复杂。
