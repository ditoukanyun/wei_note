# 前端性能优化清单

## 加载优化

- 减少首屏关键资源体积。
- 图片使用合适格式、尺寸和懒加载。
- 使用 HTTP 缓存、预加载和 CDN。
- 对路由和大模块做 [[代码分割]]。

## 渲染优化

- 避免长任务阻塞主线程。
- 控制不必要的组件重渲染。
- 大列表使用 [[虚拟列表]]。
- 为图片和异步内容预留尺寸，降低 CLS。
