# Java 定时任务分享

## 背景与目标

独立分享主题：**4.3 定时任务 ElasticJob 用法**。

通过前端定时器、Node.js 调度、分组处理和重试的类比，讲清最小 Job、分片参数、双实例执行、控制台手动触发与失败补偿。案例为 12 笔订单的分片补偿，只启动 ElasticJob 应用、ZooKeeper 与 PostgreSQL。

听众有 Java 基础；标准版 42 分钟，含 37 分钟主体与 5 分钟自由问答，紧凑版仍保留 33 分钟主体。不要求事先阅读或运行配置中心分享。
