# ElasticJob 独立案例验证记录

日期：2026-10-21。环境：Apple 芯片 Mac、Docker Desktop、Linux arm64 容器。

## 构建

- 独立 Compose 项目 `java-job-share` 构建并启动成功。
- Java 测试 4 项全部通过：失败恢复、并发幂等、事务回滚、批量与分片范围。
- Maven 不引入 Nacos 客户端；运行时不连接 Nacos 或 Apollo。

## 范围

手动触发使用真实 ElasticJob API，页面为教学控制台。单元测试使用 H2，端到端使用真实 PostgreSQL。未演练 failover、misfire 或真实远程退款；示例的业务效果是同库流水。Windows、amd64 与公司离线网络需在目标环境验证。
