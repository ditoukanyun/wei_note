## 2026-10-22 断网与重启实测

仍为 Apple 芯片 Mac 与 Linux arm64 容器，Nacos 客户端及服务端均为 2.5.1。通过 Docker CLI 实际停止、重启并恢复相关容器，结果如下：

| 条件 | 实测结果 |
| --- | --- |
| 开发采用开启 / 3 后停止 Nacos | 运行中的实例甲继续返回 3 笔，启动标识不变 |
| 重启前检查 SDK 目录 | 实例甲容器中已存在配置磁盘快照 |
| 保留同一容器并重启 Java 进程 | 容器 ID 不变，但启动失败并进入重启策略 |
| 启动无缓存的新探针 | `app-cold` 启动失败，退出码 1 |
| 恢复 Nacos | 健康检查恢复，实例甲重新就绪 |
| 实验清理 | 恢复实验前开发配置，移除探针 |
| 随后回归基础验证 | `docker compose run --rm verify` 退出码 0，最终恢复开发 false / 100、测试 false / 7 |
