# 本地项目文档

本目录记录服务器上各个 Git 仓库的说明文档，一个仓库对应一个 Markdown 文件。

## 项目列表

| 项目名称 | 路径 | 说明文档 |
|---------|------|---------|
| daily_stock_analysis | `/code/daily_stock_analysis` | [daily_stock_analysis.md](./daily_stock_analysis.md) |
| wei_note | `/code/wei_note` | [wei_note.md](./wei_note.md) |

## 文档模板

每个项目文档应包含：
- 项目简介
- 主要功能
- 技术栈
- 常用命令
- 配置文件位置
- 注意事项
