# Java 两篇独立分享大纲

首次准备先读 [[2026-10-21_Java两篇分享快速上手]]，按“跑案例 → 读关键代码 → 复述自测”分别学习两篇，再进入完整讲稿彩排。

## 第一篇：4.1 配置中心 Apollo / Nacos

入口：[[Java配置中心分享]]。

主线：前端 `.env` 的配置外置 → 远程配置与 feature flag → Apollo / Nacos 的配置定位 → 动态刷新 → 多环境隔离。

- 业务场景：订单列表功能开关与每页数量。
- 演示：发布开发 true / 3，不重启改变业务返回，测试环境保持不变。
- 沉淀：[[配置中心命名规则]]。
- 材料：[[配置中心分享讲稿]]、[[Apollo与前端配置类比]]、[[配置中心演示手册]]。
- Docker：独立 Nacos 与应用；无任务、数据库或 ZooKeeper 依赖。

## 第二篇：4.3 ElasticJob 定时任务

入口：[[Java定时任务分享]]。

主线：浏览器定时器 → Node.js 调度 → 多实例协调 → 最小 Job → 分片 → 手动触发 → 失败补偿与幂等。

- 业务场景：按区域分片补偿 12 笔订单。
- 演示：两实例三分片，11 成功 1 失败，恢复后 12 成功，额外重跑无新增流水。
- 沉淀：[[ElasticJob任务代码模板]]。
- 材料：[[ElasticJob分享讲稿]]、[[前端定时器与ElasticJob类比讲解]]、[[ElasticJob演示手册]]。
- Docker：独立任务应用、ZooKeeper 与数据库；无 Nacos / Apollo 依赖。
