# 初中生活词拆解动画 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成一个包含 `breakfast`、`classroom`、`homework` 的初中生活词拆解动画 MP4。

**Architecture:** 使用 Node 脚本按时间轴生成 SVG 帧，用 `sharp` 渲染 PNG，再用临时安装的 `ffmpeg-static` 编码为 MP4。源码与产物放在 `50_资源/英语学习/`，临时帧放在 `.superpowers/`。

**Tech Stack:** Node.js、sharp、ffmpeg-static。

---

### Task 1: 生成脚本与视频

**Files:**
- Create: `50_资源/英语学习/生成初中生活词拆解动画.mjs`
- Create: `50_资源/英语学习/初中生活词拆解动画.mp4`

- [x] **Step 1: 创建视频生成脚本**

脚本定义 3 个单词的场景、拆词、中文记忆钩子和时间轴，并输出 PNG 帧。

- [x] **Step 2: 编码 MP4**

运行脚本后调用 `ffmpeg-static`，把帧序列编码为 H.264 MP4。

- [x] **Step 3: 验证输出**

用 `ffprobe` 验证文件存在、格式为 MP4、时长约 21 秒。
