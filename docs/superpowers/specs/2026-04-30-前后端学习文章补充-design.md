# 知识库前后端学习文章补充设计

## 背景

当前 `40_知识库/前端开发` 已覆盖 HTML、CSS、JavaScript、Vue、React、Webpack、浏览器、网络、算法、设计模式、Nginx、Docker 等内容；`40_知识库/后端开发` 已覆盖 Java、SpringBoot、MySQL、Redis、分布式与系统设计相关内容。现有体系偏基础与框架专题，现代前端工程化、前端质量体系、后端云原生、安全认证、搜索与可观测性仍有补充空间。

## 目标

在不新增“全栈路线”目录的前提下，继续把学习文章放入现有 `前端开发` 和 `后端开发` 目录，通过专题文章和 MOC 索引形成可持续扩展的学习路线。

## 目录组织

### 前端开发

仍放在 `40_知识库/前端开发` 下，建议新增或完善以下专题：

- TypeScript
- Vite
- Next.js
- 前端测试
- 前端性能
- 前端安全

每个专题按“基础概念 → 原理机制 → 工程实践 → 面试延伸”的顺序逐步扩展。可新增 `前端开发学习路线 MOC.md`，把已有文章与新增文章串成学习顺序。

### 后端开发

仍放在 `40_知识库/后端开发` 下，建议新增或完善以下专题：

- 认证授权
- PostgreSQL
- 消息队列
- Elasticsearch
- 云原生与部署
- 可观测性

SpringBoot 强相关内容继续放在 SpringBoot 体系中；跨语言、跨框架的后端能力放在独立专题中。可新增 `后端开发学习路线 MOC.md`，连接 Java、SpringBoot、数据库、缓存、消息、搜索、部署与监控文章。

## 第一批文章

## 链接关系

- 前端 MOC 末尾链接到后端的 API 设计、认证授权、部署与可观测性专题。
- 后端 MOC 末尾链接到前端的构建、性能、安全与测试专题。
- 每篇总览文章先包含：学习目标、核心概念、推荐阅读顺序、后续可拆分文章。
- 后续拆分文章通过 wikilink 回链到对应总览和 MOC。

## 不做的事情

- 不创建新的 `全栈开发` 目录。
- 不一次性生成所有细分文章。
- 不改变现有目录主结构。
- 不把文章做成纯面试题库，面试延伸只作为每篇文章的附属部分。

## 验收标准

- 新增内容仍归属于 `前端开发` 和 `后端开发` 两个既有目录。
- 第一批文章覆盖 6 个前端专题和 6 个后端专题。
- 每篇文章都能作为专题入口，后续可以自然拆分出更细文章。
- MOC 能把已有文章和新增文章连接成可学习路线。
