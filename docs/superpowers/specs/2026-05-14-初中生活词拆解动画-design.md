# 初中生活词拆解动画设计

## 目标
生成一个 MP4 样片，用“生活画面 + 单词拆解”的方式帮助记忆初中生活高频英语词。

## 词汇范围
第一版使用 3 个生活高频词：

- `breakfast`：早餐
- `classroom`：教室
- `homework`：家庭作业

## 动画结构
每个单词约 7 秒，按同一节奏呈现：

1. 生活场景出现，先建立语义。
2. 英文单词居中出现。
3. 单词拆成两个熟悉部分。
4. 中文记忆钩子出现。
5. 单词重新合体，并给出中文含义。

## 视觉风格
使用简洁、明亮、适合初中生的扁平矢量风格。画面避免复杂装饰，重点突出单词、拆解块和中文记忆句。

## 输出
输出文件为：

`50_资源/英语学习/初中生活词拆解动画.mp4`
