## 技能安装方法记录

### ClawHub 技能安装（推荐）
由于直接使用 `clawhub install` 会遇到 API 限速，使用以下方法可以成功安装：

```bash
# 安装技能（使用最新版 clawhub）
npx clawhub@latest install <skill-name> --workdir /root/.openclaw/workspace --dir skills

# 示例
npx clawhub@latest install find-skills --workdir /root/.openclaw/workspace --dir skills
npx clawhub@latest install remind --workdir /root/.openclaw/workspace --dir skills
```

### Skills.sh 技能安装（备用）
如果 ClawHub 仍有限速，可以使用 skills.sh 生态系统：

```bash
# 搜索技能
npx skills find <关键词>

# 安装技能
npx skills add <owner/repo@skill> -g -y

# 示例
npx skills find remind
npx skills add sundial-org/awesome-openclaw-skills@remind-me -g -y
```
