## 投资原则

1. **长期主义** — 关注企业价值，而非短期波动
2. **风险控制** — 仓位管理优先，不孤注一掷
3. **持续学习** — 跟踪产业趋势，更新认知框架
4. **纪律执行** — 制定计划，严格执行，定期复盘
